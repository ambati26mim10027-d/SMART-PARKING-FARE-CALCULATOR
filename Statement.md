# Problem Statement

## The Problem
Many car parks still work things out by hand. A staff member has to figure out how much each driver owes, based on how long they parked and what type of vehicle they have. This takes time and can lead to mistakes, especially when the car park is busy.

## The Solution
This project is a Python program that works out a parking fee automatically. The driver types in their name, license plate number, vehicle type, and how many hours they parked. The program checks the details are valid, then works out the fee using set hourly rates. It also stops stays longer than 24 hours and charges a flat rate for stays longer than 12 hours.

## Objective
The aim of this project is to build a simple, working program that:
- Takes the driver's details
- Works out the parking fee correctly for two wheelers and for three or four wheelers
- Handles wrong or invalid inputs without crashing
- Shows a clear result on the screen

## Scope
This version handles one vehicle at a time through the terminal. It does not save records, print receipts, or connect to a real payment system. It focuses only on working out the correct fee.

## Expected Outcome
By the end, the program should take a driver's input, check that it is valid, and print the correct parking fee every time, following the pricing rules built into the code.
